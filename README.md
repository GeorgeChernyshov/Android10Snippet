### Android 10 showcase

An extensive demonstration of all changes and new features [Android 10](https://developer.android.com/about/versions/10) brings to the table:
- Adoption of Single-Activity design philosophy to make apps more concise
- Scoped storage was added to make data access much more secure
- Background actions were restricted - you can no longer just collect user location or start activities in background
- Protection of device-specific information like technical characteristics, MAC address and contacts information.
- Dark theme
- Wi-Fi P2P and Wi-FI Suggest
- Media-style notifications
And much, much more
